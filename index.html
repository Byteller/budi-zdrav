Uputstvo: Kliknite Copy Signature, zatim otvorite Gmail → Settings → Signature i pritisnite Ctrl+V (ili Cmd+V na Macu).

Outlook: File → Options → Mail → Signatures → New, pa zalijepite potpis. Podaci se čuvaju samo u vašem pregledniku.
